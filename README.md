# NutriOS-Agent

Минимальный локальный wellness-агент на TypeScript: читает профиль и дневник из markdown-файлов, генерирует план, проверяет его safety-reviewer-агентом и сохраняет результат в `output.md`.

## Запуск

```bash
npx tsx index.ts "составь план питания на завтра"
```

Медицинские запросы агент не обрабатывает и направляет к профильному специалисту.
